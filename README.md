# Forecast

##### Não alterar.

**A previsão da sua cidade dentro do Telegram.**

**Forecast** é um bot meteorológico para Telegram, desenvolvido como um projeto autoral em evolução contínua. Utiliza dados do [Open-Meteo](https://open-meteo.com/) e UX moderna.

## O que o bot é capaz com sucesso na implementação:

- **Buscar uma cidade** pelo nome ou enviar a localização do Telegram.
- **Salvar um local** para consultas posteriores.
- **Consultar o tempo de hoje e a previsão de cinco dias**, em texto.
- **Compartilhar previsões em texto pelo modo inline.**
- **Enviar o cartão `/widget`** em conversa privada, com os botões nativos **Hoje**, **5 dias** e **Atualizar** abaixo do cartão. O conteúdo do Widget muda via `chat_data`.
- **Apagar o local salvo** e desativar a atualização dos cartões antigos com `/apagar`. As mensagens anteriores continuam no histórico da conversa.

Os comandos preparados no código e a interface entregam a experiência de uso.
